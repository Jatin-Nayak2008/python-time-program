# Python Time Program

A beginner Python program that takes a time in 12-hour format,
validates it, and displays an appropriate greeting.

## Features

- Takes time as user input
- Separates hours, minutes, and AM/PM
- Validates hours and minutes
- Validates AM/PM input
- Displays morning, afternoon, evening, or night
- Uses `if`, `elif`, and `else`
- Uses logical operators `and` and `or`
- Uses `split()` and type conversion

## Example


**Input:** `5:30 Pm`

**Output:** `Good evening sir`
